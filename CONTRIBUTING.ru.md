## Morrowind Screenshots

Цель проекта - в поиске скрытой красоты и воспевании визуальной эстетики [Morrowind](#morrowind). Авторы проекта создают
оригинальные [скриншоты и видео из игры, а также рисунки](#post-types), которые затем
[рассматриваются редактором](#editing) и отбираются для [публикации](#publication) во всех аккаунтах проекта. Проект
следует [основным принципам](#core-principles). Любой желающий может [принять участие в проекте](#contributing). Код и
материалы проекта распространяются по открытым [лицензиям](#license).

## Основные принципы

Проект [Morrowind Screenshots](#mwscr) следует основным принципам, которые никогда не будут изменены. Не приветствуются
[графические и нелорные моды](#no-mods). Нельзя использовать [обработку](#no-processing). Не должен быть виден
[пользовательский интерфейс](#no-ui).

Чтобы ваша работа могла [быть принята](#proposal) в раздел [Посты](#posts), нужно выполнить описанные строгие требования
и избегать других возможных [нарушений](#violations). В противном случае можно рассчитывать на попадание в раздел
[Материалы](#extras), который более демократичен.

<a id="no-mods"></a>

### Без модификаций

В игре не должно быть контентных или [графических модификаций](#vanilla-look), кроме
[разрешённых модификаций](#allowed-mods). Ваш скриншот не будет рассматриваться для раздела [Посты](#posts), если на нём
есть текстуры, модели, объекты или ситуации, которых не могло быть в оригинальной игре с дополнениями.

> **Возможное нарушение:** Использование модов

<a id="no-processing"></a>

### Без обработки

Скриншоты и видео, заранее обработанные в графическом редакторе, не принимаются.
[Незначительная обработка](#allowed-processing) допускается только во время [редактуры](#editing). Если вы всё же хотите
предложить собственный вариант обработки, обязательно отправьте также исходное изображение.

<a id="no-ui"></a>

### Без элементов интерфейса

Для раздела [Посты](#posts) все элементы интерфейса (прицел, карта, полосы здоровья, меню, консоль и т. п.) должны быть
скрыты с экрана. Отключить интерфейс можно консольной командой `tm` или `ToggleMenus`, а в движке [OpenMW](#openmw)
можно использовать клавишу `F11` для той же цели.

> **Возможное нарушение:** Видимый интерфейс

## Типы постов

Типы постов раздела [Посты](#posts) должны соответствовать [основным принципам](#core-principles):

| Тип                      | Соотношения сторон     | Файлов | Мин. сторона | Макс. длит. | Требования                               |
| ------------------------ | :--------------------- | -----: | -----------: | ----------- | ---------------------------------------- |
| [Кадр](#shot)            | 1:1, 3:2               |      1 |        800px |             |                                          |
| [Подборка](#compilation) | 1:1, 3:2, 16:9, 9:19.5 |      4 |        800px |             | Только ранее опубликованные изображения. |
| [Обои](#wallpaper)       | 16:9, 9:19.5           |      1 |        800px |             |                                          |
| [Клип](#clip)            | 1:1, 9:16              |      1 |       1080px | 1 минута    |                                          |
| [Видео](#video)          | 16:9                   |      1 |       1080px | 1 час       |                                          |

Типы постов раздела [Материалы](#extras) более демократичны:

| Тип                        | Файлов | Требования                      |
| -------------------------- | -----: | ------------------------------- |
| [Перерисовка](#redrawing)  |      2 | Включает оригинальный кадр.     |
| [Невошедшее](#outtakes)    |     10 |                                 |
| [Новость](#news)           |        | Обязательно текстовое описание. |
| [Фотомонтаж](#photoshop)   |      2 | Включает оригинальный скриншот. |
| [Упоминание](#mention)     |      1 |                                 |
| [Мерч](#merch)             |     1+ |                                 |
| [Достижение](#achievement) |     1+ |                                 |

<a id="shot"></a>

### Кадр

Квадратный 1:1 или прямоугольный 3:2 скриншот. Самый популярный [тип постов](#post-types) в
[Morrowind Screenshots](#mwscr).

[Перейти к кадрам](https://mwscr.dehero.ru/posts/?type=shot)

<a id="compilation"></a>

### Подборка

[Тип поста](#post-types), представляющий собой набор из 4 ранее опубликованных [Постов](#posts) другого типа,
объединённых общей темой или идеей. Все материалы должны иметь одинаковое [соотношение сторон](#aspect-ratio).

[Перейти к подборкам](https://mwscr.dehero.ru/posts/?type=compilation)

<a id="wallpaper"></a>

### Обои

[Тип поста](#post-types), содержащий скриншот, созданный для использования в качестве обоев рабочего стола или
смартфона, в горизонтальной и вертикальной ориентации.

[Перейти к обоям](https://mwscr.dehero.ru/posts/?type=wallpaper)

<a id="clip"></a>

### Клип

[Тип поста](#post-types) с коротким видео до 1 минуты, рассчитанный на социальные ленты. Используется для коротких
самостоятельных моментов; более длинные и горизонтальные видео относятся к типу [Видео](#video).

[Перейти к клипам](https://mwscr.dehero.ru/posts/?type=clip)

<a id="video"></a>

### Видео

[Тип поста](#post-types) с длинным видео. Используется для продолжительных записей — там, где короткого [Клипа](#clip)
недостаточно.

[Перейти к видео](https://mwscr.dehero.ru/posts/?type=video)

<a id="redrawing"></a>

### Перерисовка

[Тип поста](#post-types) «перерисовка» должен быть основан на ранее опубликованном [Кадре](#shot) и включать его вторым
изображением для сравнения, с указанием [автора оригинала](#post-author).

[Перейти к перерисовкам](https://mwscr.dehero.ru/extras/?type=redrawing)

<a id="outtakes"></a>

### Невошедшее

[Тип поста](#post-types) с подборкой из 10 скриншотов [Morrowind](#morrowind), которые нарушают
[строгие правила проекта](#violations), но выглядят интересно.

[Перейти к невошедшему](https://mwscr.dehero.ru/extras/?type=outtakes)

<a id="news"></a>

### Новость

[Тип поста](#post-types) с новостями проекта. Должен содержать текст новости в описании и может включать необязательную

[Перейти к новостям](https://mwscr.dehero.ru/extras/?type=news)

<a id="photoshop"></a>

### Фотомонтаж

оригинальный скриншот для сравнения.

[Перейти к фотомонтажам](https://mwscr.dehero.ru/extras/?type=photoshop)

### Упоминание

[Перейти к упоминаниям](https://mwscr.dehero.ru/extras/?type=mention)

<a id="merch"></a>

### Мерч

[Тип поста](#post-types), описывающий отдельные предметы мерча, которые можно заказать, чтобы поддержать проект.

## Участие

Чтобы принять участие в проекте, вы можете [отправить скриншоты, видео или рисунки](#proposal) для публикации,
[создать подборку](#creating-compilation) из опубликованных скриншотов, [запросить скриншот или видео](#request),
описав, что вы хотели бы увидеть, [найти отсутствующую локацию](#suggesting-location) для постов без локации или
[улучшить репозиторий](#improve-repository) на GitHub.

<a id="proposal"></a>

### Предложить работу

Перед тем как предложить свои скриншоты, видео или рисунки, прочитайте [основные принципы](#core-principles) и
[советы по съёмке](#shooting-tips). Затем отправьте работу любым удобным способом. Укажите адреса своих профилей, если
хотите, чтобы при публикации работы в посте была ссылка на вас. Предложенные работы будут автоматически проверены и
попадут в [Черновики](#drafts). После [редактуры](#editing) ваши работы будут [опубликованы](#publication) или
[отклонены](#trash). Отправляя работу, вы соглашаетесь, что она будет храниться в архиве проекта и может использоваться
в любых связанных с проектом источниках с указанием вашего авторства.

[Отправить Telegram-боту](https://t.me/mwscrbot)  
[Отправить предложение через GitHub Issues](https://github.com/dehero/mwscr/issues/new?labels=post-proposal&template=post-proposal.yml) (см.
[ограничения на размер файлов](https://docs.github.com/en/get-started/writing-on-github/working-with-advanced-formatting/attaching-files))  
[Отправить администратору по email](mailto:me@dehero.site?subject=mwscr)

<a id="creating-compilation"></a>

### Создание подборки

Щелкните правой кнопкой мыши (или выполните долгое нажатие) по опубликованному посту, чтобы открыть контекстное меню.
Нажмите кнопку "Выбрать", чтобы начать выбор постов, затем выберите посты, которые хотите объединить в подборку.
Используйте фильтры и сортировку, чтобы найти посты в списке.

После выбора всех нужных постов нажмите "Собрать подборку" на панели инструментов, чтобы создать черновик подборки. Для
создания [Подборки](#compilation), которую можно опубликовать, нужны 4 скриншота.

<a id="request"></a>

### Запросить скриншот или видео

Чтобы попросить авторов проекта сделать определённый скриншот или видео, оставьте сообщение в свободной форме любым
удобным способом. Проще всего написать комментарий или личное сообщение администратору в любом из аккаунтов проекта.
Другой вариант — воспользоваться [диалогом](https://mwscr.dehero.ru/#post-request/drafts) на сайте проекта, чтобы затем
отправить свой запрос как патч. Ваш запрос будет добавлен в [Черновики](#drafts) и останется там в ожидании подходящего
материала. Запрос может быть отклонён, если он не соответствует [основным принципам](#core-principles).

<a id="suggesting-location"></a>

### Найти недостающую локацию

Если место съёмки скриншота или видео не указано в посте, вы можете предложить его. Перейдите на страницу поста или
щёлкните по посту правой кнопкой мыши (долгое нажатие), чтобы открыть контекстное меню. Нажмите кнопку «Указать локацию»
и выберите локацию из списка в диалоге. При необходимости можно выбрать несколько локаций.

Отправьте предложение любым из доступных в диалоге способов. Другой вариант — написать комментарий с предлагаемой
локацией под постом в любом из каналов проекта. Администратор проекта проверит ваше предложение и примет его, если оно
подтвердится.

## Участники

Информация об участниках проекта хранится в
[списке участников](https://github.com/dehero/mwscr/blob/main/data/users.yml). Для каждого участника проект сохраняет
отображаемое имя, аватар, необязательное написание имени на русском языке и ссылки на профили в аккаунтах проекта:
[Telegram](https://t.me/mwscr), [VK](https://vk.com/mwscr), [Instagram](https://instagram.com/mwscr/) и других.
Участник, управляющий проектом, помечается как [администратор](#admin).

По активности участника проект определяет роли: [автор](#author), [художник](#drawer), [искатель](#locator),
[запросивший](#requester), [комментатор](#commenter), [подписчик](#follower) и [новичок](#beginner). У участников без
известной активности роль [чужеземец](#foreigner). На странице [Участники](https://mwscr.dehero.site/users/) сайта
отображаются эти роли, число постов, которые участник [предложил](#proposal), [указал](#suggesting-location),
[запросил](#request) или прокомментировал, а также собранные лайки, просмотры и [рейтинг](#post-rating) опубликованных
работ.

[Перейти к Участникам](https://mwscr.dehero.site/users/)

<a id="admin"></a>

### Администратор

Участник, управляющий проектом. Администратор отмечен явно в [списке участников](#members) и может редактировать данные
проекта, рассматривать [черновики](#drafts) и публиковать посты.

<a id="author"></a>

### Автор

Участник, чья работа была опубликована. Роль присваивается, когда участник указан как [автор](#post-author)
опубликованной работы в разделе [Посты](#posts) или [Материалы](#extras).

<a id="drawer"></a>

### Художник

Участник, предложивший рисунок. Роль присваивается первому [автору](#post-author) работы типа [Перерисовка](#redrawing)
в опубликованных постах, материалах или [черновиках](#drafts).

<a id="locator"></a>

### Искатель

Участник, подсказавший [место съёмки](#suggesting-location) для опубликованного поста. Роль присваивается, когда хотя бы
одно предложенное участником место было принято для раздела [Посты](#posts).

<a id="requester"></a>

### Запросивший

Участник, попросивший проект сделать определённый [пост](#request). Роль присваивается, когда запрос участника был
выполнен в опубликованном посте или ожидает в [черновиках](#drafts).

<a id="commenter"></a>

### Комментатор

Участник, оставивший комментарий под опубликованными [постами](#posts) или [материалами](#extras) в
[каналах проекта](#mwscr).

<a id="follower"></a>

### Подписчик

Участник, подписанный на проект [Morrowind Screenshots](#mwscr) хотя бы в одном из его аккаунтов (на данный момент эта

<a id="shooting-tips"></a>

## Советы по съёмке

Чтобы было проще делать качественные снимки, используйте подходящий
[игровой движок и утилиты](#game-engine-and-utilities), выбирайте [формат файла](#file-format) без потерь, учитывайте
[соотношение сторон](#aspect-ratio), на ходу настраивайте [фокусное расстояние](#fov) и [время суток](#gamehour),
управляйте [дальностью прорисовки и туманом](#distance), всегда используйте [свободную камеру](#free-camera) и
[режим бога](#god-mode), старайтесь [быстро двигаться](#player-speed) и не стесняйтесь пользоваться
[быстрым перемещением](#quick-travel).

Также помните о [вспомогательных плагинах](#allowed-mods), которые упрощают процесс съёмки.

<a id="game-engine-and-utilities"></a>

### Игровой движок и утилиты

Желательно использовать последнюю версию движка [OpenMW](#openmw) или оригинальный движок с [MGE](#mge). Нужно
установить высокое разрешение и включить сглаживание. Можно включить небольшие графические улучшения, например шейдеры
воды. Можно увеличить количество загружаемых ячеек в экстерьерах, но использовать Distant Land не рекомендуется. Чтобы
делать скриншоты на оригинальном движке, используйте клавишу `PrtScn`, а в OpenMW - клавишу `F12`. Для записи видео
можно использовать программы захвата экрана, например OBS Studio. В посте указывается движок, использованный для съёмки:
OpenMW или Vanilla.

<a id="openmw"></a>

#### OpenMW

Воссоздание [игрового движка](#game-engine-and-utilities) для [Morrowind](#morrowind), бесплатное и с открытым исходным
кодом. Призвано решить проблемы ванильного движка, который больше не поддерживается и не получает исправлений ошибок.
Используется для большей части контента проекта.

[Сайт OpenMW](https://openmw.org/)

<a id="mge"></a>

#### Morrowind Graphics Extender

Дополнение к оригинальному движку, улучшающее графику: увеличивает дальность обзора, даёт красивые закаты, качественные
шейдеры и улучшенное освещение. Как [модификация движка](#game-engine-and-utilities), оно несовместимо с
[OpenMW](#openmw).

[Скачать MGE](https://www.nexusmods.com/morrowind/mods/41102)

<a id="aspect-ratio"></a>

### Соотношение сторон

Учитывайте, что перед публикацией ваш скриншот или видео [могут быть кадрированы](#allowed-processing), поэтому все
важные объекты должны попадать в итоговый формат, а композиция при этом - оставаться уравновешенной. Для простоты можно
специально запустить игру в окне с нужным соотношением сторон. Распространённый сценарий — запустить игру в окне с
разрешением 1080x1080, самым частым размером изображения для [Кадров](#shot).

Разрешённые соотношения сторон с рекомендуемыми и минимальными размерами:

| Соотношение сторон | Рекомендуемый | Минимальный |
| ------------------ | :-----------: | :---------: |
| 16:9               |   1920x1080   |  1920x1080  |
| 3:2                |   1620x1080   |  1200x800   |
| 1:1                |   1080x1080   |   800x800   |
| 9:16               |   1080x1920   |  1080x1920  |
| 9:19.5             |   1080x2340   |  1080x2340  |

<a id="fov"></a>

### Фокусное расстояние

Можно на ходу менять фокусное расстояние в настройках игры, увеличивая его, чтобы в кадр попадало больше объектов, или
наоборот - уменьшая, чтобы взять крупный план. Действуйте в разумных пределах, не допуская сильного искажения
перспективы.

<a id="distance"></a>

### Дальность прорисовки и туман

Управляйте дальностью прорисовки в настройках игры в зависимости от своего художественного замысла. Иногда лучше скрыть
отдалённый фон дымкой, чтобы не отвлекать внимание зрителя от основных объектов на переднем плане. Для съёмки дальних
планов можно слегка увеличить дальность прорисовки. При этом стоит следить, чтобы вид игры оставался близким к
оригинальному.

<a id="free-camera"></a>

### Свободная камера

Консольная команда `tcl` или `ToggleCollision` включает режим свободной камеры, в котором можно свободно левитировать и
проходить сквозь стены. Это помогает получать интересные кадры с труднодоступных ракурсов.

<a id="god-mode"></a>

### Режим бога

Консольная команда `tgm` или `ToggleGodMode` защищает от урона при падении и атак персонажей, позволяя сосредоточиться
на съёмке и не беспокоиться о здоровье главного героя. Плагин [NoFightNoHello](#nofightnohello) тоже может защитить от
атак персонажей, но с ним будет сложнее снимать боевые сцены.

<a id="quick-travel"></a>

### Быстрое перемещение

Чтобы переместиться в экстерьер без названия, введите его координаты в консоли:

```
coe 10 -5
```

Чтобы переместиться в именованный экстерьер или интерьер, введите его название:

```
coc "Ald-ruhn, Manor District"
```

<a id="player-speed"></a>

### Скорость передвижения

Чтобы сильно ускорить персонажа, введите в консоли:

```
player->setspeed 500
```

Можно задавать и более высокие значения. Это помогает быстрее перемещаться по миру при поиске мест для съёмки. Когда
место для съёмки найдено, обычно нужно подобрать более точный ракурс, замедлив движение. Чтобы сделать персонажа
максимально медленным, введите:

```
player->setspeed 0
```

<a id="gamehour"></a>

### Время суток

При съёмке в экстерьере бывает полезно настроить освещение или расположение лун, изменив время суток. Например, если
нужно снять закат в 19:00, задайте час в консоли:

```
set gamehour to 19
```

<a id="allowed-mods"></a>

## Разрешённые модификации

Разрешены официальные дополнения Tribunal и Bloodmoon от Bethesda Softworks, а также неофициальные дополнения из белого
списка, в который сейчас входит только [Tamriel Rebuilt](#tamriel-rebuilt). Также разрешены плагины, которые дают
дополнительные возможности при съёмке, но не меняют игру визуально, например [NoFightNoHello](#nofightnohello),
[MannequinChallenge](#mannequinchallenge) и [TrackPath](#trackpath).

В посте указывается дополнение из белого списка, явно задействованное в работе.

<a id="tamriel-rebuilt"></a>

### Tamriel Rebuilt

Известное неофициальное дополнение от команды Tamriel Rebuilt Project, добавляющее материковую территорию в
[Morrowind](#morrowind).

[Сайт](https://www.tamriel-rebuilt.org/)

<a id="nofightnohello"></a>

### NoFightNoHello

[Плагин](#allowed-mods), который отключает приветственные фразы и убирает агрессию у всех NPC и существ. Позволяет
делать скриншоты, не отвлекаясь от игрового процесса.

[Скачать](https://mwscr.dehero.ru/plugins/NoFightNoHello.esp)

<a id="mannequinchallenge"></a>

### MannequinChallenge

[Плагин](#allowed-mods), который накладывает постоянный эффект паралича на NPC или существо. Он позволяет зафиксировать
персонажа на одном месте, чтобы упростить съёмку. Чтобы применить эффект, откройте консоль, выберите персонажа и
введите:

```
addspell mannequinchallenge
```

Чтобы снять эффект, введите:

```
removespell mannequinchallenge
```

[Скачать](https://mwscr.dehero.ru/plugins/MannequinChallenge.esp)

<a id="trackpath"></a>

### TrackPath

[Плагин](#allowed-mods), позволяющий записывать движение игрока по трём координатам и затем плавно воспроизводить его.
Подходит для подготовки плавного перемещения по игровому миру при съёмке видео. Хорошо работает только на движке
[OpenMW](#openmw).

Чтобы начать запись движения игрока, откройте консоль и введите:

```
set trackPath to 1
```

Появится сообщение о том, что началась запись пути `PATH_NUMBER`. Этот номер нужно запомнить, чтобы позже воспроизвести
записанный путь. Перемещайте персонажа по игровому миру. Можно переходить между локациями, активируя двери; запись
движения продолжится. Чтобы остановить запись движения игрока, введите в консоли:

```
set trackPath to 0
```

Перед воспроизведением записанного пути нужно переместить персонажа в исходную локацию, где находится начало пути. Чтобы
воспроизвести записанный путь `PATH_NUMBER`, введите в консоли:

```
set playPath to PATH_NUMBER
```

Путь начнёт воспроизводиться, плавно перемещая персонажа по миру. Переход между локациями не происходит автоматически.
Чтобы продолжить воспроизведение пути, нужно вручную активировать двери, когда вы окажетесь рядом с ними.
Воспроизведение пути можно прервать командой:

```
set playPath to 0
```

[Скачать](https://mwscr.dehero.ru/plugins/TrackPath.esp)

## Редактура

Процесс отбора и подготовки постов к публикации. Редактура выполняется администратором проекта и включает поиск
[нарушений](#violations), [объединение постов](#merging-posts), [разрешённую обработку](#allowed-processing) и
[подготовку поста](#preparing-post). За процессом редактуры можно следить, наблюдая за [Черновиками](#drafts).

<a id="violations"></a>

### Нарушения

Контент поста проверяется автоматически и вручную; если обнаружены нарушения, пост перемещается в [Отклонённые](#trash).
К распространённым нарушениям относятся [неподходящий контент](#appropriate-content), [неподдерживаемый](#file-format) и
[недоступный](#available-resource) ресурс.

Если вы рассчитываете, что ваш пост будет опубликован в разделе [Посты](#posts), также избегайте более строгих
нарушений: [неванильный вид](#vanilla-look), [отсутствие сглаживания](#anti-aliasing),
[артефакты JPEG](#no-jpeg-artifacts), [графические проблемы](#no-graphic-issues) и нарушения
[основных принципов](#core-principles).

<a id="appropriate-content"></a>

#### Подходящий контент

Подходящим контентом считаются оригинальные, ранее не опубликованные скриншоты и видео, снятые в игре
[Morrowind](#morrowind), а также перерисовки ранее опубликованных постов, фотографии, фотомонтажи, скриншоты вне игры и
другие материалы, связанные с проектом или игрой. Если речь идёт о [заявках на посты](#request), они должны быть
написаны ясно и не содержать нецензурной лексики.

> **Возможное нарушение:** Неподходящий контент

<a id="file-format"></a>

#### Формат файла

Проект поддерживает следующие форматы файлов:

| Тип                    | Форматы         | Макс. размер | Примечания                                                             |
| ---------------------- | --------------- | :----------: | ---------------------------------------------------------------------- |
| Изображения без потерь | PNG, BMP        |    10 Мб     |                                                                        |
| Изображения с потерями | JPEG, WEBP, GIF |     5 Мб     |                                                                        |
| Видео                  | MP4, AVI        |    200 Мб    | Мин. длительность 10 сек, мин. частота кадров 30 fps, высокий битрейт. |
| Архив                  | ZIP             |    100 Мб    |                                                                        |

Для удобной передачи файлы также можно упаковать в архив "ZIP". Максимальный размер может быть меньше в зависимости от
способа отправки.

> **Возможное нарушение:** Неподдерживаемый ресурс

<a id="available-resource"></a>

#### Доступный ресурс

Проект Morrowind Screenshots может работать с разными типами URL ресурсов. Ссылки "store:/" ведут к файлам, хранящимся в
собственном закрытом хранилище проекта. Ссылки "uploads:/" ведут к файлам, загруженным через сайт проекта; такие файлы
временные и удаляются примерно через неделю, если на них не ссылается сохранённый черновик или патч. Ссылки "http://" и
"https://" ведут на внешние ресурсы.

При добавлении ссылок вручную всегда проверяйте, что в ссылке нет опечаток и что она доступна без авторизации.

> **Возможное нарушение:** Недоступный ресурс

<a id="vanilla-look"></a>

#### Ванильный вид

При съёмке для раздела [Посты](#posts) избегайте слишком большой [дальности прорисовки](#distance), Distant Land,
броских теней, цветовых шейдеров и других визуальных эффектов, которые противоречат оригинальной эстетике
[Morrowind](#morrowind).

Помните, что таинственный туман, сдержанная цветовая гамма и странные угловатые формы - важная часть атмосферы нашей
любимой игры. Цель не в том, чтобы показать возможности модов, а в том, чтобы раскрыть красоту самой игры.

> **Возможное нарушение:** Неванильный вид

<a id="anti-aliasing"></a>

#### Сглаживание

Скриншоты и видео для раздела [Посты](#posts) следует снимать с включённым сглаживанием. Если вы используете
[OpenMW](#openmw), откройте Launcher, перейдите в раздел "Graphics" и на вкладке "Display" установите "Anti-aliasing"
на 8. Если вы используете ванильный движок с [MGE](#mge), перейдите на вкладку "Global graphics", найдите раздел "Scene"
и установите "Antialiasing level" на 8x.

> **Возможное нарушение:** Отсутствие сглаживания

<a id="no-jpeg-artifacts"></a>

#### Без артефактов JPEG

Скриншоты для раздела [Посты](#posts) должны изначально сохраняться в графическом формате "PNG" или "BMP" (без сжатия).
Нельзя переводить изображения, изначально сохранённые как "JPEG", в "PNG", чтобы обойти это ограничение. Артефакты
сжатия остаются заметны на изображении и портят чистоту исходного скриншота.

> **Возможное нарушение:** Артефакты JPEG

<a id="no-graphic-issues"></a>

#### Без графических проблем

При съёмке для раздела [Посты](#posts) следует избегать скриншотов и видео, где игрок находится за пределами игрового
мира, видны обрезанные края моделей, одни модели пересекаются с другими или присутствуют другие графические ошибки и
недочёты.

> **Возможное нарушение:** Графические проблемы

<a id="merging-posts"></a>

### Объединение постов

Несколько вариантов одной и той же работы в [черновиках](#drafts) объединяются в один пост, чтобы было проще выбрать,
какой вариант опубликовать. Если работа является ответом на один из ожидающих [запросов](#request), она объединяется с
исходным запросом в один пост.

Щелкните правой кнопкой мыши (или выполните долгое нажатие) по посту, чтобы открыть контекстное меню. Нажмите кнопку
"Выбрать", чтобы начать выбор постов, затем выберите посты, которые хотите объединить. Нажмите "Объединить выбранные" на
панели инструментов, чтобы объединить выбранные посты в один пост.

<a id="allowed-processing"></a>

### Разрешённая обработка

Материалы, добавленные в [Черновики](#drafts), можно обрабатывать в графическом редакторе во время
[редактуры](#editing). Обработка предназначена для улучшения восприятия оригинальной работы при максимально возможном
сохранении исходного содержания. Она может включать кадрирование, настройку яркости, исправление технических ошибок при
съёмке (в редких случаях), обрезку по длительности (для видео). Запрещено изменять цветовую гамму, применять фильтры,
добавлять, изменять или искажать объекты. При обработке исходные файлы остаются нетронутыми, а каждый новый вариант
сохраняется в отдельный файл с номером варианта, добавленным к имени файла. Например:

```txt
dehero.2024-02-17-10-53-36.png
dehero.2024-02-17-10-53-36.1.png
dehero.2024-02-17-10-53-36.2.png
```

<a id="drafts"></a>

### Черновики

Место, где хранятся все входящие [скриншоты, видео, рисунки](#proposal) и [запросы на посты](#request). Все могут
видеть, что было предложено и что планируется к публикации. [Редактура](#editing) выполняется над материалами из
Черновиков.

[Открыть](https://mwscr.dehero.ru/drafts/)

<a id="preparing-post"></a>

### Подготовка поста

Подготовка поста включает выбор [типа и содержания](#post-types), [названия](#post-title), [автора](#post-author),
заполнение [тегов](#post-tags), [игрового движка](#game-engine-and-utilities), [дополнения](#allowed-mods), места
[съёмки](#post-location) и выбор [метки редактора](#post-mark).

<a id="post-title"></a>

#### Название поста

Название поста подбирается по содержанию и может как просто описывать изображённое, так и расширять восприятие поста с
помощью аналогий, отсылок и других приёмов. Также учитывается название, предложенное автором работы. Название нужно
заполнить на английском языке и перевести на русский.

<a id="post-author"></a>

#### Автор поста

Участник проекта, предложивший оригинальную работу для публикации. Для постов типа [Перерисовка](#redrawing) первый
автор - автор рисунка, а второй автор - автор исходного поста. Для постов типа [Подборка](#compilation) указываются
авторы всех изображений в наборе. Каждый из указанных авторов должен быть предварительно внесён в
[список участников](#members).

<a id="post-tags"></a>

#### Теги поста

Теги поста заполняются на основе содержания поста латинскими буквами через пробел. Посты с похожим содержанием должны
получать похожие теги, чтобы было проще находить посты на одну тему. Информации, указанной в других полях поста, в тегах
следует избегать.

<a id="post-location"></a>

#### Локация поста

Указывает игровую локацию, представленную в посте, согласно
[списку локаций](https://github.com/dehero/mwscr/blob/main/data/locations.yml). Главная цель — дать ориентир, по
которому место можно найти в игре; точное положение внутри этой локации не требуется. Для снимков в экстерьере по
возможности указывайте не только регион, но и изображённый объект или ближайший ориентир, например кораблекрушение или
плантацию. Дополнительные сведения, например номер ячейки экстерьера, можно указать в заметке при выборе локации.
Указать только регион может быть недостаточно: впоследствии к кадру будет сложно вернуться и уточнить место. Если
никакую локацию определить не удаётся, [её можно предложить](#suggesting-location) позже.

<a id="post-mark"></a>

#### Метка редактора

Метка редактора помогает фильтровать [Черновики](#drafts) и следить за общим качеством ленты постов проекта
[во время редактуры](#editing).

| Метка  | Описание                                                                                                        |
| ------ | --------------------------------------------------------------------------------------------------------------- |
| A1, A2 | Посты первого класса, самые красивые и художественные                                                           |
| B1, B2 | Более обычные посты, но всё ещё достаточно хорошие                                                              |
| C      | Редкие не очень хорошие, но пригодные к публикации посты                                                        |
| E      | Экспериментальные посты, которые кажутся интересными, но без уверенности                                        |
| D      | Слишком обычные или дублирующие посты, переносятся в [Отклонённые](#trash)                                      |
| F      | Неудачные варианты постов, кандидаты на пересъёмку или повторное рассмотрение, хранятся в [Отклонённых](#trash) |

Метка выбирается редактором по следующим показателям:

| Показатель       | A1  | A2  | B1  | B2  |  C  |  D  |  E  |  F  | Оценивается                              |
| ---------------- | :-: | :-: | :-: | :-: | :-: | :-: | :-: | :-: | ---------------------------------------- |
| Художественность |  +  |  +  |  ±  |     |     |     |  ±  |     | Красота, замысел.                        |
| Опрятность       |  +  |  +  |  ±  |  +  |     |     |     |     | Графика, кадрирование.                   |
| Композиция       |  +  |  ±  |  +  |  ±  |  ±  |     |  ±  |     | Ракурс, расстановка объектов.            |
| Освещение        |  +  |  ±  |  +  |  ±  |  ±  |     |  ±  |     | Свет и цвета.                            |
| Эксперимент      |     |     |     |     |     |     |  +  |     | Нестандартный взгляд.                    |
| Фэйл             |     |     |     |     |     |     |     |  +  | Потенциал для пересъёмки или пересмотра. |
| Публикуется      |  ✓  |  ✓  |  ✓  |  ✓  |  ✓  |     |  ✓  |     |                                          |

Работа получит указанную в заголовке метку, если в столбце заполнены все показатели, помеченные +, и хотя бы один
показатель, помеченный ±.

Учитывайте, что метка субъективна, а более объективным является [рейтинг поста](#post-rating), который оценивает
опубликованные посты по реакциям подписчиков.

<a id="publication"></a>

## Публикация

Посты из [Черновиков](#drafts), успешно прошедшие [редактуру](#editing), попадают в шорт-лист, откуда постепенно берутся
для создания новых постов. Каждый день выбирается один новый пост. Пост публикуется одновременно во всех аккаунтах
проекта, поддерживающих данный тип постов. Ранее опубликованные посты могут публиковаться повторно, без изменений, либо
в рамках другого [типа постов](#post-types). Текст поста включает: [название](#post-title), описание (при наличии),
[автора](#post-author) (если автором не является администратор проекта), имя запросившего пост (если пост сделан по
запросу), [теги](#post-tags), [локацию](#post-location) (при наличии).

[Опубликованные посты](https://mwscr.dehero.ru/posts/)  
[Шорт-лист](https://mwscr.dehero.ru/drafts/?publishable=true)

<a id="post-statistics"></a>

### Статистика постов

Для каждой публикации [поста](#publication) в аккаунтах проекта собираются число подписчиков аккаунта на момент
публикации, лайки, просмотры, репосты и комментарии с ответами. Эти значения обновляются некоторое время после
публикации: в течение первых суток — каждые 15 минут, в течение первой недели — ежедневно, далее — раз в неделю.

Из собранных значений проект вычисляет [рейтинг](#post-rating) и вовлечённость поста, а также суммарное число лайков,
просмотров и комментариев. Статистика отображается на страницах [Посты](#posts) и [Материалы](#extras) и на странице
каждого поста, а также определяет [вклад](#members) участников в проект.

<a id="post-rating"></a>

### Рейтинг поста

Рейтинг поста рассчитывается для опубликованных постов как среднее отношение подписчиков к лайкам в процентах. Значения
берутся из всех аккаунтов [Morrowind Screenshots](#mwscr), где пост когда-либо был опубликован.

<a id="contribution"></a>

### Вклад участников

Вклад [участников](#members) вычисляется по их активности во всех разделах и каналах проекта. Для каждого участника
проект считает, сколько работ он [предложил](#post-author), сколько [локаций](#post-location) указал, сколько работ
[запросил](#request) и сколько комментариев оставил.

Сортировка по вкладу сравнивает эти счётчики в порядке: предложено, указано, запрошено, прокомментировано, а разделы — в
порядке: Посты, Материалы, Черновики, Отклонённые. Участники с равными счётчиками упорядочиваются по идентификатору.
