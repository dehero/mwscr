# file format

The project supports lossless "PNG" and "BMP" images, lossy "JPEG", "WEBP" and "GIF" images, "MP4" and "AVI" video file
formats. Files can also be folded into a "ZIP" archive for easy transfer.

---

# формат файла

Проект поддерживает изображения без потерь в форматах "PNG" и "BMP", изображения с потерями в форматах "JPEG", "WEBP" и
"GIF", а также видеофайлы в форматах "MP4" и "AVI". Для удобной передачи файлы также можно упаковать в архив "ZIP".
