# file format

The project supports the following file formats:

| Type              | Formats         | Max size | Notes                                                    |
| ----------------- | --------------- | :------: | -------------------------------------------------------- |
| Images (lossless) | PNG, BMP        |  10 MB   |                                                          |
| Images (lossy)    | JPEG, WEBP, GIF |   5 MB   |                                                          |
| Video             | MP4, AVI        |  200 MB  | Min duration 10 sec, min framerate 30 fps, high bitrate. |
| Archive           | ZIP             |  100 MB  |                                                          |

Files can also be folded into a "ZIP" archive for easy transfer. The maximum size may be lower depending on the
submission method.

---

# формат файла

Проект поддерживает следующие форматы файлов:

| Тип                    | Форматы         | Макс. размер | Примечания                                                             |
| ---------------------- | --------------- | :----------: | ---------------------------------------------------------------------- |
| Изображения без потерь | PNG, BMP        |    10 Мб     |                                                                        |
| Изображения с потерями | JPEG, WEBP, GIF |     5 Мб     |                                                                        |
| Видео                  | MP4, AVI        |    200 Мб    | Мин. длительность 10 сек, мин. частота кадров 30 fps, высокий битрейт. |
| Архив                  | ZIP             |    100 Мб    |                                                                        |

Для удобной передачи файлы также можно упаковать в архив "ZIP". Максимальный размер может быть меньше в зависимости от
способа отправки.
