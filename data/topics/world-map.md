# world map

The project site has a world map used to view and select [shooting locations](./post-location.md) on post pages and in
the location filter. The map covers the base game and the [Bloodmoon](./allowed-mods.md) addon, the islands of
Vvardenfell and Solstheim. The [Tribunal](./allowed-mods.md) addon has no additional locations on the world map.
Locations of the unofficial [Tamriel Rebuilt](./tamriel-rebuilt.md) addon are deliberately not included in the project.

The map is based on the original game map of [Morrowind](./morrowind.md).

# карта мира

На сайте проекта есть карта мира, используемая для просмотра и выбора [места съёмки](./post-location.md) на страницах
постов и в фильтре по локациям. Карта охватывает базовую игру и дополнение [Bloodmoon](./allowed-mods.md), острова
Вварденфелл и Солстхейм. В дополнении [Tribunal](./allowed-mods.md) нет дополнительных локаций на карте мира. Локации
неофициального дополнения [Tamriel Rebuilt](./tamriel-rebuilt.md) в проект намеренно не включены.

Карта создана на основе оригинальной игровой карты [Morrowind](./morrowind.md).
