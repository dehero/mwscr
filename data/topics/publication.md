# publication

[Drafts](./drafts.md) posts that have successfully passed [editing](./editing.md) are placed to the shortlist, from
where they are gradually taken to create new posts. A new post is selected every day. The post is published
simultaneously on all project accounts that support this type of post. Previously published posts may be published
again, without changes, or as part of a different [post type](./post-types.md). The text of the post includes:
[title](./post-title.md), description (if any), [author](./post-author.md) (if the author is not the project
administrator), requester (if the post was made by request), [tags](./post-tags.md), [location](./post-location.md) (if
available).

# публикация

Посты из [Черновиков](./drafts.md), успешно прошедшие [редактуру](./editing.md), попадают в шорт-лист, откуда постепенно
берутся для создания новых постов. Каждый день выбирается один новый пост. Пост публикуется одновременно во всех аккаунтах
проекта, поддерживающих данный тип постов. Ранее опубликованные посты могут публиковаться повторно, без изменений, либо в
рамках другого [типа постов](./post-types.md). Текст поста включает: [название](./post-title.md), описание (при наличии),
[автора](./post-author.md) (если автором не является администратор проекта), имя запросившего пост (если пост сделан по
запросу), [теги](./post-tags.md), [локацию](./post-location.md) (при наличии).
