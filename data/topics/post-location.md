# post location

Specifies the game location that is represented in the post according to the location list. The goal is to provide a
practical landmark for finding the place in the game; the exact position within that place is not required. For exterior
shots, specify both the region and, when possible, the object shown or the nearby landmark, such as a shipwreck or a
plantation. Additional details, such as an exterior cell number, can be added in the note when selecting a location.
Specifying only the region may not be sufficient: it may later be difficult to return to the shot and determine the
location more precisely. If no location can be determined, [it can be suggested](./suggesting-location.md) later.

# локация поста

Указывает игровую локацию, представленную в посте, согласно списку локаций. Главная цель — дать ориентир, по которому
место можно найти в игре; точное положение внутри этой локации не требуется. Для снимков в экстерьере по возможности
указывайте не только регион, но и изображённый объект или ближайший ориентир, например кораблекрушение или плантацию.
Дополнительные сведения, например номер ячейки экстерьера, можно указать в заметке при выборе локации. Указать только
регион может быть недостаточно: впоследствии к кадру будет сложно вернуться и уточнить место. Если никакую локацию
определить не удаётся, [её можно предложить](./suggesting-location.md) позже.
