# post types

Posts [in main section](./posts.md) must meet the [core principles](./core-principles.md) and the following
requirements:

| Type                            | Aspect ratios          | Content | Min side | Max duration | Requirements                        |
| ------------------------------- | :--------------------- | ------: | -------: | ------------ | ----------------------------------- |
| [Shot](./shot.md)               | 1:1, 3:2               |       1 |    800px |              |                                     |
| [Compilation](./compilation.md) | 1:1, 3:2, 16:9, 9:19.5 |       4 |    800px |              | Only previously published images.   |
| [Series](./series.md)           | 1:1, 3:2               |       3 |    800px |              | Only previously unpublished images. |
| [Wallpaper](./wallpaper.md)     | 16:9, 9:19.5           |       1 |    800px |              |                                     |
| [Clip](./clip.md)               | 1:1, 9:16              |       1 |   1080px | 1 minute     |                                     |
| [Video](./video.md)             | 16:9                   |       1 |   1080px | 1 hour       |                                     |

The [Extras](./extras.md) section is more democratic and includes:

| Type                            | Content | Requirements                                             |
| ------------------------------- | ------: | -------------------------------------------------------- |
| [Redrawing](./redrawing.md)     |       2 | Includes the original shot.                              |
| [Outtakes](./outtakes.md)       |      10 |                                                          |
| [Photoshop](./photoshop.md)     |       2 | Includes the original shot.                              |
| [Mention](./mention.md)         |         | A [snapshot](./post-media.md) is required.               |
| [News](./news.md)               |         | A [text description](./post-description.md) is required. |
| [Merch](./merch.md)             |      1+ |                                                          |
| [Achievement](./achievement.md) |      1+ |                                                          |

# типы постов

Посты [в основном разделе](./posts.md) должны соответствовать [основным принципам](./core-principles.md) и следующим
требованиям:

| Тип                          | Соотношения сторон     | Контент | Мин. сторона | Макс. длит. | Требования                               |
| ---------------------------- | :--------------------- | ------: | -----------: | ----------- | ---------------------------------------- |
| [Кадр](./shot.md)            | 1:1, 3:2               |       1 |        800px |             |                                          |
| [Подборка](./compilation.md) | 1:1, 3:2, 16:9, 9:19.5 |       4 |        800px |             | Только ранее опубликованные изображения. |
| [Серия](./series.md)         | 1:1, 3:2               |       3 |        800px |             | Только ранее неопубликованные кадры.     |
| [Обои](./wallpaper.md)       | 16:9, 9:19.5           |       1 |        800px |             |                                          |
| [Клип](./clip.md)            | 1:1, 9:16              |       1 |       1080px | 1 минута    |                                          |
| [Видео](./video.md)          | 16:9                   |       1 |       1080px | 1 час       |                                          |

Раздел [Материалы](./extras.md) более демократичен и включает в себя:

| Тип                            | Контент | Требования                                               |
| ------------------------------ | ------: | -------------------------------------------------------- |
| [Перерисовка](./redrawing.md)  |       2 | Включает оригинальный кадр.                              |
| [Невошедшее](./outtakes.md)    |      10 |                                                          |
| [Фотомонтаж](./photoshop.md)   |       2 | Включает оригинальный кадр.                              |
| [Упоминание](./mention.md)     |         | Обязателен [снэпшот](./post-media.md).                   |
| [Новость](./news.md)           |         | Обязательно [текстовое описание](./post-description.md). |
| [Мерч](./merch.md)             |      1+ |                                                          |
| [Достижение](./achievement.md) |      1+ |                                                          |
