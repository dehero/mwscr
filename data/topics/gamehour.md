# time of day

When shooting exteriors, it can be useful to adjust the lighting or moon position by changing the time of day. For
example, to shoot during sunset at 7:00 PM, set the hour in the console:

```
set gamehour to 19
```

---

# время суток

При съёмке в экстерьере бывает полезно настроить освещение или расположение лун, изменив время суток. Например, если
нужно снять закат в 19:00, задайте час в консоли:

```
set gamehour to 19
```
