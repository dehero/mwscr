# no interface elements

For [Posts](./posts.md) section all interface elements (crosshair, map, health bars, menu, console, etc.) should be
hidden from the screen. You can disable the interface with the console command `tm` or `ToggleMenus`, or in the
[OpenMW](./openmw.md) engine with the `F11` key.

---

# без элементов интерфейса

Для раздела [Посты](./posts.md) все элементы интерфейса (прицел, карта, полосы здоровья, меню, консоль и т. п.) должны
быть скрыты с экрана. Отключить интерфейс можно консольной командой `tm` или `ToggleMenus`, а в движке
[OpenMW](./openmw.md) можно использовать клавишу `F11` для той же цели.
