# no interface elements

For [Posts](./posts.md) section all interface elements (crosshair, map, health bars, menu, console, etc.) should be
hidden from the screen. You can disable the interface with the console command "tm" or "ToggleMenus". In the
[OpenMW](./openmw.md) engine, you can use the "F11" key for the same purpose.

---

# без элементов интерфейса

Для раздела [Посты](./posts.md) все элементы интерфейса (прицел, карта, полосы здоровья, меню, консоль и т. п.) должны быть
скрыты с экрана. Отключить интерфейс можно консольной командой "tm" или "ToggleMenus". В движке
[OpenMW](./openmw.md) для той же цели можно использовать клавишу "F11".
