# post description

An optional text field of a post that supplements the [title](./post-title.md) and gives additional context. The
description is filled in English and translated into Russian. It uses Markdown syntax, so links can be inserted into it.

```
Learn [Markdown syntax](https://www.markdownguide.org/basic-syntax/)
```

The description is shown in the published post and is taken into account when searching posts. For [News](./news.md)
posts the description is required and contains the news text.

---

# описание поста

Необязательное текстовое поле поста, дополняющее [название](./post-title.md) и дающее дополнительный контекст. Описание
заполняется на английском языке и переводится на русский. В нём используется синтаксис Markdown, поэтому можно вставлять
ссылки.

```
Изучите [синтаксис Markdown](https://www.markdownguide.org/basic-syntax/)
```

Описание показывается в опубликованном посте и учитывается при поиске постов. Для постов типа [Новость](./news.md)
описание обязательно и содержит текст новости.
