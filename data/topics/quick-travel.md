# quick travel

To travel to an exterior without a name, type its coordinates in the console:

```
coe 10 -5
```

To travel to a named exterior or to an interior, type its name:

```
coc "Ald-ruhn, Manor District"
```

---

# быстрое перемещение

Чтобы переместиться в экстерьер без названия, введите его координаты в консоли:

```
coe 10 -5
```

Чтобы переместиться в именованный экстерьер или интерьер, введите его название:

```
coc "Ald-ruhn, Manor District"
```
