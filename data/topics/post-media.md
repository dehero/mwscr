# post media

A post stores its files in three fields.

Content is the main media of a post: the screenshot, video, drawing or set of images it is about. Content files are
cropped to the post [aspect ratio](./aspect-ratio.md) when it is set and are shown in full when it is not. It is mostly
the content that is used for [publications](./publication.md).

Snapshot is a screenshot (not from [the game](./morrowind.md)) or other photographic evidence that serves as the basis
for a post. It is always shown in full size with scrolling. For [Mentions](./mention.md) it is the main media, since
this post type has no content. For other types this field is optional and can be used when necessary.

Trash stores files rejected during the [editing](./editing.md) of a post. Their previews are kept in the project for
history, but they are not counted in any way, not [published](./publication.md) and not shown anywhere.

# медиа поста

Пост хранит свои файлы в трёх полях.

Контент — основная медиа поста: скриншот, видео, рисунок или набор изображений, о которых этот пост. Файлы контента
кадрируются под [соотношение сторон](./aspect-ratio.md) поста, если оно задано, и показываются в полном размере, если
нет. В основном именно контент используется для [публикаций](./publication.md).

Снэпшот — скриншот (не из [игры](./morrowind.md)) или другое фотодоказательство, служащее основой для поста. Всегда
показывается в полном размере с прокруткой. Для [Упоминаний](./mention.md) это основная медиа, так как у этого типа
постов нет контента. Для других типов это поле опционально и может использоваться при необходимости.

Корзина хранит файлы, отбракованные в процессе [редактуры](./editing.md) поста. Их превью остаются в проекте для
истории, но они никак не учитываются, не [публикуются](./publication.md) и нигде не показываются.
