# editor's mark

The editor's mark helps to filter [Drafts](./drafts.md) and monitor the overall quality of the project's post feed
[during editing](./editing.md).

| Mark   | Description                                                                                    |
| ------ | ---------------------------------------------------------------------------------------------- |
| A1, A2 | First-class posts, the most beautiful and artistic                                             |
| B1, B2 | More ordinary posts, but still good enough                                                     |
| C      | Rare not very good but publishable posts                                                       |
| E      | Experimental posts, which seem interesting but without certainty                               |
| D      | Too ordinary or doubling posts, which should be deleted to [Rejects](./trash.md)               |
| F      | Failed post attempts, candidates for reshooting or revisiting, stored in [Rejects](./trash.md) |

The mark is selected by the editor by the following indicators:

| Indicator   | A1  | A2  | B1  | B2  |  C  |  D  |  E  |  F  | Evaluated                               |
| ----------- | :-: | :-: | :-: | :-: | :-: | :-: | :-: | :-: | --------------------------------------- |
| Artistry    |  +  |  +  |  ±  |     |     |     |  ±  |     | Beauty, intent.                         |
| Neatness    |  +  |  +  |  ±  |  +  |     |     |     |     | Graphics, framing.                      |
| Composition |  +  |  ±  |  +  |  ±  |  ±  |     |  ±  |     | Foreshortening, placement of objects.   |
| Lighting    |  +  |  ±  |  +  |  ±  |  ±  |     |  ±  |     | Light and colors.                       |
| Experiment  |     |     |     |     |     |     |  +  |     | Unconventional view.                    |
| Fail        |     |     |     |     |     |     |     |  +  | Potential for reshooting or revisiting. |
| Publishable |  ✓  |  ✓  |  ✓  |  ✓  |  ✓  |     |  ✓  |     |                                         |

A work receives the mark of a column if all indicators marked + are filled in and at least one indicator marked ± is
filled in.

Keep in mind that the mark is subjective and there is a more objective [post rating](./post-rating.md) score that
evaluates published posts by subscribers reactions.

# метка редактора

Метка редактора помогает фильтровать [Черновики](./drafts.md) и следить за общим качеством ленты постов проекта
[во время редактуры](./editing.md).

| Метка  | Описание                                                                                                            |
| ------ | ------------------------------------------------------------------------------------------------------------------- |
| A1, A2 | Посты первого класса, самые красивые и художественные                                                               |
| B1, B2 | Более обычные посты, но всё ещё достаточно хорошие                                                                  |
| C      | Редкие не очень хорошие, но пригодные к публикации посты                                                            |
| E      | Экспериментальные посты, которые кажутся интересными, но без уверенности                                            |
| D      | Слишком обычные или дублирующие посты, переносятся в [Отклонённые](./trash.md)                                      |
| F      | Неудачные варианты постов, кандидаты на пересъёмку или повторное рассмотрение, хранятся в [Отклонённых](./trash.md) |

Метка выбирается редактором по следующим показателям:

| Показатель       | A1  | A2  | B1  | B2  |  C  |  D  |  E  |  F  | Оценивается                              |
| ---------------- | :-: | :-: | :-: | :-: | :-: | :-: | :-: | :-: | ---------------------------------------- |
| Художественность |  +  |  +  |  ±  |     |     |     |  ±  |     | Красота, замысел.                        |
| Опрятность       |  +  |  +  |  ±  |  +  |     |     |     |     | Графика, кадрирование.                   |
| Композиция       |  +  |  ±  |  +  |  ±  |  ±  |     |  ±  |     | Ракурс, расстановка объектов.            |
| Освещение        |  +  |  ±  |  +  |  ±  |  ±  |     |  ±  |     | Свет и цвета.                            |
| Эксперимент      |     |     |     |     |     |     |  +  |     | Нестандартный взгляд.                    |
| Фэйл             |     |     |     |     |     |     |     |  +  | Потенциал для пересъёмки или пересмотра. |
| Публикуется      |  ✓  |  ✓  |  ✓  |  ✓  |  ✓  |     |  ✓  |     |                                          |

Работа получит указанную в заголовке метку, если в столбце заполнены все показатели, помеченные +, и хотя бы один
показатель, помеченный ±.

Учитывайте, что метка субъективна, а более объективным является [рейтинг поста](./post-rating.md), который оценивает
опубликованные посты по реакциям подписчиков.
