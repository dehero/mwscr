# merging posts

Multiple variants of the same work in [Drafts](./drafts.md) are merged into a single post to make it easier to choose
which variant to publish. If the work is a response to one of the pending [requests](./request.md), it is merged with
the original request into a single post.

Right click (long tap) on a post to show the context menu. Click "Select" button to start selecting posts, then select
the posts you want to merge. Click "Merge Selected" on the toolbar to merge selected posts into a single post.

# объединение постов

Несколько вариантов одной и той же работы в [черновиках](./drafts.md) объединяются в один пост, чтобы было проще
выбрать, какой вариант опубликовать. Если работа является ответом на один из ожидающих [запросов](./request.md), она
объединяется с исходным запросом в один пост.

Щелкните правой кнопкой мыши (или выполните долгое нажатие) по посту, чтобы открыть контекстное меню. Нажмите кнопку
"Выбрать", чтобы начать выбор постов, затем выберите посты, которые хотите объединить. Нажмите "Объединить выбранные" на
панели инструментов, чтобы объединить выбранные посты в один пост.
