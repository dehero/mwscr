# merging posts

Multiple variants of the same work in [Drafts](./drafts.md) are merged into a single post to make it easier to choose
which variant to publish. If the work is a response to one of the pending requests, it is merged with the original
request into a single post.

---

# объединение постов

Несколько вариантов одной и той же работы в [черновиках](./drafts.md) объединяются в один пост, чтобы было проще выбрать,
какой вариант опубликовать. Если работа является ответом на один из ожидающих запросов, она объединяется с исходным
запросом в один пост.
