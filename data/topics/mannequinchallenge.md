# MannequinChallenge

[A plugin](./allowed-mods.md) that applies a permanent paralysis effect to an NPC or creature. Allows you to lock a
character in one place to make shooting easier. To apply the effect, you need to open the console, select the character,
and type "addspell mannequinchallenge". To remove the effect type "removespell mannequinchallenge".

[Download](/plugins/MannequinChallenge.esp)

# MannequinChallenge

[Плагин](./allowed-mods.md), который накладывает постоянный эффект паралича на NPC или существо. Он позволяет
зафиксировать персонажа на одном месте, чтобы упростить съёмку. Чтобы применить эффект, откройте консоль, выберите
персонажа и введите "addspell mannequinchallenge". Чтобы снять эффект, введите "removespell mannequinchallenge".

[Скачать](/plugins/MannequinChallenge.esp)
